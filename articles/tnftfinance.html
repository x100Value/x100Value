What this project is

Что это за проект

TNFTFinance is a security-first working baseline for TON testnet experiments in NFT-backed lending and related DeFi workflows. It includes protocol prototypes, contract artifacts, mini app prototypes, and deployment scripts structured for controlled iteration.

TNFTFinance - это security-first рабочая база для TON testnet экспериментов в NFT-обеспеченном кредитовании и смежных DeFi-сценариях. Репозиторий включает прототипы протокола, контрактные артефакты, mini app-прототипы и скрипты деплоя для контролируемой итерации.

Why it exists

Для чего проект

The main goal is to validate protocol and product assumptions before any mainnet move. Instead of rushing into production, the project formalizes security checklists, repeatable deploy flow, and testnet-only execution gates.

Главная цель - валидировать протокольные и продуктовые гипотезы до выхода в mainnet. Вместо быстрого перехода в прод, репозиторий фиксирует security-чеклисты, воспроизводимый деплой-процесс и testnet-only контрольные ворота.

Security model

Модель безопасности

The project enforces strict secret hygiene and explicitly blocks unsafe mainnet behavior until all checklists are complete. This makes TNFTFinance not just a codebase, but an operational safety framework for experimental finance products.

Репозиторий требует строгой гигиены секретов и явно блокирует небезопасный переход в mainnet до закрытия всех чеклистов. Поэтому TNFTFinance - это не только кодовая база, но и операционный контур безопасности для экспериментальных финансовых продуктов.

Current stage and product purpose

Текущая стадия и продуктовая цель

Current stage: active testnet baseline with structured prototype tracks. Product purpose: de-risk the path from concept to deployable lending system by proving architecture, security process, and user flow before scaling.

Текущая стадия: активная testnet-база со структурированными прототипными треками. Продуктовая цель: снизить риски пути от концепта до готовой к деплою lending-системы через проверку архитектуры, процесса безопасности и пользовательского сценария до масштабирования.
