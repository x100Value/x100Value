What this project is

Что это за проект

tg-llm-router is a Telegram Mini App that gives one interface for multiple LLM providers. Instead of forcing users to learn several tools, it routes requests to available models and automatically switches when a model is overloaded or unavailable.

tg-llm-router - это Telegram Mini App с единым интерфейсом для нескольких LLM-провайдеров. Вместо необходимости использовать разные инструменты, проект маршрутизирует запросы к доступным моделям и автоматически переключается при перегрузке или недоступности модели.

Why it exists

Для чего проект

The project targets a practical pain point: users want stable AI access directly in Telegram, without dealing with provider switching, account fragmentation, and quality instability. The router turns this into one product layer that can be embedded into user, team, and agent workflows.

Проект решает практичную проблему: пользователям нужен стабильный доступ к AI прямо в Telegram без ручного переключения провайдеров, разрозненных аккаунтов и нестабильного качества. Роутер превращает это в единый продуктовый слой для личных, командных и агентных сценариев.

Core capabilities

Ключевые возможности

  • Single Telegram UI with model routing and automatic switching.
  • SSE streaming for real-time response output.
  • Support for personal API keys for users who prefer direct control.
  • Role-oriented product model: user, business, AI agent, developer.
  • Security controls: initData validation, rate limits, encrypted key handling.
  • Единый Telegram-интерфейс с маршрутизацией моделей и автоматическим переключением.
  • SSE-стриминг для вывода ответов в реальном времени.
  • Поддержка личных API-ключей для пользователей, которым нужен прямой контроль.
  • Ролевой продуктовый контур: user, business, AI agent, developer.
  • Контроль безопасности: валидация initData, rate limit, шифрование ключей.

Architecture and stack

Архитектура и стек

Frontend is built on React and Telegram WebApp SDK. Backend is Node.js/Express with PostgreSQL for persistent data. The infrastructure uses nginx, SSL, and service-level deployment, while router logic refreshes available models and selects the best available path automatically.

Фронтенд построен на React и Telegram WebApp SDK. Бэкенд - Node.js/Express с PostgreSQL для постоянных данных. Инфраструктура использует nginx, SSL и сервисный деплой, а логика роутера обновляет доступные модели и автоматически выбирает лучший доступный маршрут.

Current stage and target outcome

Текущая стадия и целевой результат

The current stage is an active live product with infrastructure already running publicly. The target outcome is to become a reusable AI access infrastructure for Telegram products, with predictable quality, measurable cost control, and plug-in monetization.

Текущая стадия - активный рабочий продукт с уже работающей публичной инфраструктурой. Целевой результат - стать переиспользуемым AI-инфраструктурным слоем для Telegram-продуктов с предсказуемым качеством, контролем затрат и подключаемой монетизацией.
